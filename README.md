# VisDrone 항공 영상 사람 탐지

> 영상처리 수업 프로젝트 · **개인 작업**
> 과제 조건은 *"주어진 이미지를 인식하는 모델을 만들 것"* 뿐이었고,
> **데이터셋 선정 · 클래스 재설계 · 모델 선택 · 학습 전략은 모두 직접 결정**했습니다.

드론 항공 영상에서 사람을 탐지하는 YOLOv8 모델입니다.
작은 객체가 많고 시점이 위에서 내려다보는 형태라 일반 객체 탐지보다 난이도가 높습니다.

---

## 문제 정의

교수님이 제시한 것은 인식 대상 이미지 예시뿐이었습니다.
"이걸 인식하는 모델을 만들어라"에서 출발해, 다음을 직접 정해야 했습니다.

1. 어떤 공개 데이터셋을 쓸 것인가
2. 어떤 클래스 체계로 학습할 것인가
3. 어떤 모델과 입력 해상도를 쓸 것인가
4. 어디까지 학습시킬 것인가

---

## 설계 결정

### 1. 데이터셋 — VisDrone2019-DET

항공 시점 · 소형 객체 · 밀집 장면이라는 조건이 과제 이미지와 가장 가까워 선택했습니다.
원본은 10개 클래스(pedestrian, people, bicycle, car, van, truck, tricycle, awning-tricycle, bus, motor)입니다.

### 2. 클래스 재설계 — 10 → 1

목표가 **사람 탐지**였기 때문에, 원본의 `pedestrian`(보행 중인 사람)과 `people`(그 외 자세의 사람)을
**하나의 `person` 클래스로 병합**하고 나머지 8개 클래스를 제외했습니다.

```yaml
# configs/vis_person.yaml
nc: 1
names: ['person']
```

두 클래스를 나눠 두면 자세 차이만으로 라벨이 갈려 학습이 불안정해지고,
과제 목적상 구분할 이유도 없다고 판단했습니다.

### 3. 입력 해상도 — 960

항공 영상의 사람은 화면에서 매우 작게 나타납니다.
기본값 640으로는 다운샘플링 과정에서 특징이 사라진다고 보고 **960으로 올려** 학습했습니다.
대신 배치 크기와 학습 시간을 감수했습니다.

### 4. 학습 환경

멀티 GPU(`device: 0,1`), 100 에폭, Ubuntu + Docker 환경에서 학습했습니다.
최종 학습에 약 **4.9시간**이 소요되었습니다.

## 결과

### 학습 진행에 따른 성능 변화

| 실험 | 데이터 | 에폭 | mAP50 | mAP50-95 | Precision | Recall |
|---|---|---|---|---|---|---|
| train | VisDrone 10클래스 | 1 | 0.238 | 0.136 | — | — |
| train2 | person 1클래스 | 27 | 0.731 | 0.445 | 0.808 | 0.631 |
| **train3** | person 1클래스 | **100** | **0.755** | **0.464** | **0.826** | **0.655** |

클래스를 사람 단일로 좁힌 것만으로 mAP50이 0.238 → 0.731로 크게 올랐고,
이후 에폭을 100까지 늘려 0.755까지 개선했습니다.
27 → 100 에폭 구간의 상승폭(+0.024)이 크지 않은 것으로 보아 이 설정에서는 거의 수렴한 상태로 판단됩니다.

## 한계 및 미완 실험

### 아키텍처 실험 (미완)

YOLOv8n의 기본 블록인 **C2f를 YOLO11의 C3k2로 교체**하는 실험을 시도했습니다.
C3k2는 C2f 구조를 유지하면서 내부 bottleneck을 커널 크기 조절이 가능한 C3k로 바꾼 블록으로,
YOLO11이 더 적은 파라미터로 비슷한 정확도를 내는 요인 중 하나입니다.

COCO 데이터셋 · 600 에폭 · batch 128 · 멀티 GPU 설정으로 실행했으나,
**GPU 전원 문제로 학습이 중단되어 결과 지표를 확보하지 못했습니다.**
실행 설정만 `experiments/` 에 기록으로 남깁니다.

> 재실행한다면 baseline(C2f)과 C3k2 변형을 동일 조건에서 학습해
> mAP50-95 기준으로 비교하고, 파라미터 수와 추론 속도를 함께 측정해야 합니다.

### 그 외

- **소형 객체 성능 미분석** — VisDrone의 핵심 난점은 작은 객체인데, 객체 크기별 성능 분해는 하지 못했습니다
- **Recall 0.655** — 정밀도(0.826)에 비해 재현율이 낮아, 놓치는 사람이 상당수 있습니다. 밀집 장면에서의 미탐 분석이 필요합니다
- **단일 해상도만 실험** — 960의 효과를 640과 정량 비교하지 않았습니다

## 실행

```bash
pip install -r requirements.txt
```

VisDrone 데이터셋은 [공식 저장소](https://github.com/VisDrone/VisDrone-Dataset)에서 받아
`configs/VisDrone.yaml`의 `path`에 맞춰 배치하세요.

```bash
yolo train data=configs/vis_person.yaml model=yolov8n.pt epochs=100 imgsz=960
```
